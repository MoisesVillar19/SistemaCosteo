# SistemaCosteo
Calculadora de costos por órdenes de trabajo. Backend en Python + GUI Tkinter.

## Requisitos
- Python 3.10+
- (activar .venv) pip install -r requirements.txt

## Estructura
- core/: backend
- gui/: frontend (Tkinter)
- assets/: plantillas Excel

## Uso (rápido)
1. Activar entorno: `.venv\Scripts\activate`
2. Instalar: `pip install -r requirements.txt`
3. Ejecutar: `python main.py`

## Equipo
- Responsable A: Backend
- Responsable B: GUI
